# Twill - Terminal user interfaces in Swift

<p align="center">
    <sub>Created and maintained by <a href="https://github.com/philprime">Philip Niedertscheider</a>.</sub>
</p>

Twill is a Swift library for building terminal user interfaces on macOS and Linux.
It brings an event-driven runtime and Swift concurrency together as the foundation for interactive terminal applications.

> [!NOTE]
> Twill is in early development and the API is subject to change.
